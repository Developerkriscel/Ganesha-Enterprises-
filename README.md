# Ganesha Enterprises — Premium Luxury Website

> "We don't just print. We create impressions."

A world-class luxury website redesign and rebuild for **Ganesha Enterprises** ([ganeshaenterprises.in](https://ganeshaenterprises.in/)), engineered as a premium international digital printing, custom corporate merchandise, luxury packaging, and brand architecture platform.

## 🚀 Technology Stack

- **React 19**
- **Vite 6**
- **Tailwind CSS 3**
- **React Router DOM v7**
- **Lucide React** (Icons)
- **Canvas Confetti**

## 📂 Project Structure

```
src/
```

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
